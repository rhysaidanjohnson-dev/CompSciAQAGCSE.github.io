How to use this course

Work through every unit in order, open each practice-answer panel only after attempting the question, then complete the mixed quiz. Tick a unit as complete when you can explain every keyword without notes and answer its questions accurately.

Grade 9 habit: for longer questions, make a point, explain the mechanism, then link it explicitly to the scenario. Avoid unexplained lists.

Exam strategy

Paper 1 — 2 hours, 90 marks

Algorithms and programming. Expect tracing, writing/refining code, test data and computational thinking.

Paper 2 — 1 h 45 min, 90 marks

Data representation, systems, networks, security, SQL and social impacts.

High-mark response checklist

  • Read command words: describe = what; explain = why/how; compare = both sides; evaluate = reasoned judgement.
  • Show binary and file-size working. Include units and convert bits to bytes where required.
  • Trace code line by line using a table; do not guess outputs.
  • For programming: use meaningful names, suitable data types, validation, clear selection/iteration and test cases.
  • For ethics questions: provide a balanced benefit and risk, then reach a justified conclusion.
